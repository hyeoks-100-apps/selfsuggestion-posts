앞서 첨부한 사주핑계 원고 ZIP 전체의 편집을 이어서 완료해 줘. 내가 ZIP을 통째로 줬는데 결과가 한국어(ko) 일부만 나왔어. 앞서 작성한 한국어 수정본은 버리지 말고 보존하면서 빠진 한국어·일본어·영어 원고를 모두 마저 다듬어 줘.

1. 먼저 원본 ZIP과 이전에 네가 반환한 수정 JSON의 실제 내용을 다시 확인해. 앞서 준 ZIP에는 ko-all.json, ja-all.json, en-all.json과 같은 원고가 중복된 batches 폴더가 있을 수 있어. 이 경우 언어별 *-all.json 세 파일만 한 번씩 합치고 batches는 원본 목록에서 제외해. 새 형식의 ZIP이라면 all-posts.json 하나만 사용해. 원본 파일에 다시 접근할 수 없다면 추측해서 진행하지 말고 필요한 원본을 읽을 수 없다고 먼저 알려 줘.

2. 원본의 (id, locale) 목록을 만들고 기존 수정본과 실제로 대조해. 기존 ko 결과가 20개인지 139개인지 파일명만 보고 가정하지 마. 기존 수정본에 있는 유효한 행의 편집 내용은 유지하고, 그 외 모든 누락 행을 작업해. 한국어도 일부만 끝났다면 나머지 한국어부터 빠짐없이 포함해야 해. 같은 ID여도 ja와 en은 각각 별도의 원고이므로 반드시 해당 언어로 검토·수정해.

3. 처음 요청한 copy-editing-prompt.txt의 브랜드·말투·문장 검수·길이 제한을 적용해. ko는 친근한 도사가 옆에서 이야기하는 자연스러운 반말, ja는 일본 독자에게 익숙한 연애·생활 매거진의 일본어, en은 영어권 관계·라이프스타일 콘텐츠의 편한 영어로 다듬어. 어색한 쉼표, 추상적인 설명, 인과관계가 맞지 않는 문장, 반복하는 위로와 과장된 예측을 고쳐 줘. 한국어를 직역하지 말고 각 행의 현지 주제와 원문을 기준으로 해.

4. 결과는 세 언어를 합친 all-posts-edited.json 한 파일로 만들어. 최상위는 format="sajupinggye-instagram-copy", version=1, posts 배열만 두고 기존 v1 규격을 유지해. 행의 id, locale, baseRevision과 슬라이드 수·순서는 원본 그대로 보존해. 각 행의 topic, label, imageBrief, slides, caption, hashtags와 각 슬라이드의 eyebrow, title, body, note를 빠짐없이 유지해. 새로운 상태 필드나 설명문, JSON 주석, 마크다운 코드 블록을 파일 안에 넣지 마.

5. 반환 직전 원본과 결과의 전체 행 수, 언어별 개수, (id, locale) 집합, 각 행의 baseRevision과 슬라이드 수를 실제로 대조해. 원래 기본 ZIP은 ko 139개 + ja 139개 + en 139개 = 총 417개야. 중복·누락 없이 정확히 417개가 있어야 해. 원본 순서는 유지하고, 언어별 파일을 합쳐야 한다면 ko-all.json → ja-all.json → en-all.json 순서와 각 파일 안의 순서를 유지해.

6. 개수만 채우려고 아직 검토하지 않은 원문을 그대로 복사한 뒤 완료했다고 하지 마. 모든 누락 행을 실제로 읽고 필요한 문구를 수정해. 이미 자연스러운 문장까지 억지로 바꿀 필요는 없어. 검토 품질이 한 번에 보장된다고 약속하지 말고 마지막으로 문맥과 각 언어 표현을 살펴봐.

전체 작업이 끝나면 설명 없이 UTF-8 첨부 파일 all-posts-edited.json 하나만 반환해. 실행·출력 한도 때문에 끝내지 못하면 이 조건보다 미완료 사실을 정확히 알리는 것이 우선이야. 완료한 언어별 개수와 아직 남은 언어·ID를 알려 주고, 다음 응답에서 이어서 작업할 수 있게 진행 상황을 남겨 줘. 일부 결과나 검토하지 않은 원문을 전체 완료 파일처럼 반환하지 마.
